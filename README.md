# CQB Tactical FPS

SWAT 4 テイストのブラウザ完結型 3D CQB タクティカル FPS（Three.js + TypeScript + Vite）。

室内クリアリング、左右リーン、段階的なドア開閉・ブリーチング、フラッシュバン、警告コール（コンプライアンス）、非致死性装備、突入前の人質交渉、部隊指示（Squad）、現行犯逮捕、そして交戦規定（RoE）に基づく評価をブラウザ上で軽量に体験できます。

## 起動・ビルド方法

Node.js（v20 以降推奨）環境で以下を実行します。

```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動（Vite）
npm run dev

# 型チェック（strict モード）
npx tsc --noEmit

# 本番ビルド（型チェック＋バンドル）
npm run build

# ビルド結果のローカルプレビュー
npm run preview
```

### はじめてプレイするとき

初回だけ、画面上の吹き出しで次の 2 点を案内します（ブラウザの `localStorage` に既読を保存し、2 回目以降は表示しません）。

- **交渉フェーズ**: 「⚡ オート交渉 (A)」におまかせで OK。
- **突入後（SWAT モード）**: 仲間への指示は `Z` だけで OK（見ている場所に応じて整列・突入・移動・拘束を自動選択）。呼び戻しは `X`。

その他の操作は慣れてから覚えれば十分です。案内をもう一度見たい場合は、開発者ツールで `localStorage` の `cqb.tour.*` を削除してください。

## 収録ステージ

ステージはすべてランダム生成で、ブリーフィング画面の「② マップの広さ」から **小 / 中 / 大** を選びます（リザルト画面からも切替可）。選ぶたび・「🎲 同じ広さで別の間取りにする」を押すたびに間取りと人物配置が変わります。多階層マップではブリーフィング画面のフロアタブ（初期表示 `1F`、`B1` / `1F` / `2F`）で全階層の間取りを事前確認でき、プレイ中のミニマップもプレイヤーの現在階層に合わせて自動切り替えされます。

| ID | 広さ | 構成・特徴 |
| --- | --- | --- |
| `random_small` | **小** | `generators/house_compact.json` によるコンパクトな一戸建て（平屋 / 2F 建て / B1+1F の最大 2 階層構成）。 |
| `random_house` | **中** | `generators/house.json` による中庭付き大型邸宅（平屋 / 2F 建て / B1+1F / B1+1F+2F の全 4 階層構成）。 |
| `random_embassy` | **大** | `generators/embassy.json` による大使館複合施設（全 4 階層構成・最大 2 階段コア・中庭・地下保管庫対応）。 |

ランダム生成ステージでは外窓に加えて、隣り合う部屋の仕切り壁に**室内の窓口**（腰壁＋カウンター付きの素通し開口。通り抜けはできないが見通し・射線は通る）が生成されます（生成テンプレートの `window.interiorChance` / `interiorWidth` / `interiorSill` / `interiorHeight` / `interiorMaxPerLevel`）。

## 📞 突入前交渉フェーズ（両モード共通）

ブリーフィングの後、突入前に電話越しの交渉フェーズがあります（従来のプレイ中の交渉無線は廃止）。数字キー / クリックで選択肢を選び、`Enter` で交渉を終えてミッション開始。交渉回数は 6 回まで。

**SWAT モード（自分が交渉人）** — 犯人の「緊張」が 100 に達すると人質が 1 名殺害され交渉決裂。

| 選択肢 | 効果 |
| --- | --- |
| 信頼構築（差し入れ） | 緊張 -15・信頼 +20（犯人の士気はやや回復） |
| 人質の解放を要求 | 成功で人質 1 名が退避（保護として加点）。信頼が高く緊張が低いほど成功しやすい |
| 投降を説得 | 成功で最も弱気な犯人 1 名がその場で投降（突入後に拘束が必要） |
| 内部の様子を聞き出す | 抵抗を続ける犯人の人数と居場所の手がかり |
| 最後通告（威圧） | 全犯人の士気 -15（突入時に投降しやすい）。緊張 +30 |

**容疑者モード（自分が犯人）** — SWAT 交渉人の「忍耐」が 0 になると交渉決裂、即突入。

| 選択肢 | 効果 |
| --- | --- |
| 時間稼ぎ | 成功で突入までの準備時間 +25 秒・仲間の士気 +4（繰り返すほど見抜かれやすい）。準備時間中は仲間が籠城準備を進める |
| 人質 ⇄ 防弾チョッキ | 被弾の 60% を肩代わりする防弾チョッキ（耐久 70）。仲間の士気 -10 |
| 人質 ⇄ 弾薬 | 予備マガジン 2 本。仲間の士気 -10 |
| 人質 ⇄ 時間 | 準備時間 +40 秒。仲間の士気 -10 |
| 強気の要求で仲間を鼓舞 | 仲間の士気 +22 → +14 → +8（最大 3 回）。投降しにくく粘り強くなる。交渉人の忍耐 -10（失敗時 -20） |
| 脅迫（包囲を緩めろ） | 低確率で突入班 SWAT を 1 名減らす（最少 3 名）。失敗すると忍耐が激減 |

人質を差し出すほど装備は増えますが、「切り札を手放した」仲間は動揺し、盾も減ります。時間を稼いで籠城準備を整えるルートと天秤にかけてください。

## 🦹 容疑者モード（籠城 vs SWAT）

ブリーフィング画面の `MODE:` で **容疑者（籠城 vs SWAT）** を選ぶと、立場を逆転して立てこもり犯として SWAT 4 名を迎え撃てます（URL: `?mode=suspect`、全ステージ対応・ランダム生成ステージも可）。

- **開始位置**: ステージの容疑者配置のいずれか（突入地点から遠いほど選ばれやすい）。本来の突入地点・隊員配置が SWAT の進入地点になります。
- **武器**: 改造フルオート拳銃のみ（15 発・予備 3 本、精度・反動とも悪い）。閃光弾・非致死装備は無し。弾は交渉で補充できます。
- **準備フェーズ（30 秒・交渉で増減）**: ドアを施錠して籠城の準備。`Space` で準備を切り上げて即突入させられます。
- **勝利条件**: SWAT 全員の無力化（撃退）、または突入から 4 分間の生存（籠城成功）。
- **敗北条件**: 死亡。`Space` 長押し（1.5 秒）で投降することもできます。
- **SWAT AI**（ボディアーマー装備・高精度・高反応）: 2 人 1 組で部屋を順に掃討し、足音・ドア音・銃声を聞きつけて調査、目撃情報は無線で全隊に共有。施錠ドアはブリーチし、突入時や潜伏推定位置にはフラッシュバンを投げ込みます。全区画を探しても見つからない場合はドローンの熱源探知で大まかな位置を掴みます。傍受した SWAT 無線は画面右下に表示されます。
- **人質**: 民間人が射線上にいる間、SWAT は実弾を撃ちません（位置は把握されます）。民間人の前で `F` 長押しで人質を拘束して連れ回せます。人質の正面 ±40° にいる SWAT は実弾を撃てないため回り込みを図ります。民間人を撃つと減点。
  - **人質の抵抗**: 足取りが不規則に鈍り、不定期に暴れます（ほぼ進めない・視点がぶれる・その間は盾にならない）。抱えている時間・移動・自分の発砲・ペッパーボールで「抵抗」が溜まり、満タンになると人質は振りほどいて逃げます（10 秒間は再拘束不可）。
  - **ペッパーボール**: 人質・民間人が射線上にいる SWAT は、実弾の代わりにペッパーボールを撃ち込みます。浴びると視界がにじんでぼやけ、咳き込み、移動が遅くなり照準が大きくぶれます。人質に当たると人質が暴れ出します。
- **籠城準備**（突入前の準備時間）:
  - **窓のバリケード**: 窓・室内の窓口の前で `F` 長押し（2.4 秒）で開口全体を板で覆い、視線を完全に遮ります（もう一度長押しで外す）。板は銃で破壊でき、被弾するたびに表板が剥がれ、耐久 170（改造拳銃で約 9 発）を削り切られると破られて見通し・射線が通ります。仲間がいると、SWAT の突入口に近い窓から自動で補強していきます。
  - **ドアのブービートラップ**: 閉じたドアの前で `C`（しゃがみ）+ `F` 長押し（約 2 秒）。SWAT が開ける・蹴破ると爆発し、周囲の隊員に大ダメージ・離れた隊員も一時行動不能（自分や人質も巻き込まれる）。部材は 2 個から始まり、時間を稼ぐと仲間が追加で作ります。SWAT は近づくと一定確率でワイヤーに気付き、7〜12 秒かけて解除します（15% で解除失敗→起爆。一度トラップに遭うと以後は気付きやすくなる）。
  - **武器改造**: 仲間が十分な時間作業すると、全員の武器がアップグレード（威力・装弾数・精度・反動が改善）。
- 部隊指揮メニュー（`Tab` / 右クリック）は無効です。

| 入力 | 機能（容疑者モード） |
| --- | --- |
| `F`（タップ） / `ホイール` | ドア開閉 / 段階開閉 |
| `F`（長押し） | 照準先の閉じたドアを施錠・解錠（施錠ドアは SWAT がブリーチするまで通れない） |
| `F`（民間人の前で長押し） | 人質を拘束して連れ回す（拘束中に `F` で解放） |
| `F`（窓・窓口の前で長押し） | 板で塞ぐ / 外す |
| `C` + `F`（閉じたドアの前で長押し） | ブービートラップを仕掛ける |
| `Space` | 準備中: 準備完了（即突入） / 突入後: 長押しで投降 |
| `R` | リロード（予備弾は有限） |

## 交戦規定（RoE）とランク評価

- **加点項目**: 容疑者の現行犯逮捕（`+50`）、証拠武器の回収（`+10`）、無傷の民間人保護（`+30`）、敵対行動後の正当防衛による無力化（`+10`）
- **減点項目（RoE 違反）**: 警告なしの発砲（`-25`）、投降者・拘束済み容疑者への発砲（`-50`）、民間人への非致死性誤射（`-25`）、民間人への致死誤射（`-100`）
- **ランク評価**: ステージごとの理論最大スコアに対する到達率（`roe.json` の `minRatio`）で評価されます。
  - `S`: 85% 以上 / `A`: 65% 以上 / `B`: 40% 以上 / `C`: 15% 以上 / `D`: 15% 未満
- **ミッション終了条件**: 全容疑者が制圧（逮捕または無力化）された後、生存民間人の保護と逮捕容疑者の証拠回収がすべて完了すると自動終了します。残項目がある状態でも `Backspace` キーでいつでも手動終了できます。

## データ駆動アーキテクチャ

マップ・武器・AI・交渉・部隊・RoE などのパラメータはすべて `public/data/` 配下の JSON で管理され、起動時に `DataLoader` がスキーマおよび相互参照を検証します。

```text
public/data/
├── stages.json          # ステージ一覧マニフェスト（選択 UI に自動反映）
├── generators/          # モジュラー建築生成テンプレート（type: "modular"）
│   ├── house_compact.json
│   ├── house.json
│   └── embassy.json
├── weapons.json         # 実弾・非致死性装備・フラッシュバンのパラメータ
├── ai_profiles.json     # 容疑者・民間人の士気・戦闘・人質盾・パニック設定
├── squad.json           # 味方隊員 AI（スタック・突入・警戒・階段追従）のパラメータ
├── negotiation.json     # （旧・交渉無線の設定。現在は未使用）
├── perception.json      # AI の聴覚・視覚パラメータ
├── player.json          # 移動・足音・リーン・警告コール・逮捕/保護パラメータ
├── doors.json           # ドア高・ピーク角・開閉速度・ブリーチ設定
└── roe.json             # 交戦規定の配点・ラベル・ランク閾値（minRatio / minScore）
```

### 新規ステージの追加方法

ステージはすべてランダム生成です（固定マップは廃止）。コード変更なしで新しいステージを追加できます。

1. `public/data/generators/<generator_id>.json` に生成テンプレートを作成する（既存テンプレートの形式に準拠）。
2. `public/data/stages.json` の `stages` 配列に `{ "id": "<stage_id>", "name": "...", "size": "小", "tagline": "...", "description": "...", "generator": "<generator_id>" }` を追記する（`generator` は必須）。

### ランダム間取りステージ（モジュラー建築生成・多階層・敷地8変換）

`stages.json` の各エントリの `"generator": "<generator_id>"` で指定した `public/data/generators/<generator_id>.json` のテンプレートとシードから決定論的にマップを生成します（生成結果は `validateMap`・相互参照検証を通過。従来の `type: "house"` テンプレートとも後方互換を維持）。

- **モジュラー空間合成と動線グラフ（`type: "modular"`）**:
  - 玄関・折返し2レーン階段コア・廊下・LDK・ビルトインガレージ・中庭・寝室/スイート・書斎/執務室/会議室・地下倉庫/金庫・2Fルーフテラスなどの建築モジュールを、動線グラフ（全域木＋閉路ループ動線・隣接/禁止ルール・サブ室分割）に沿って格子スナップ単位（`snap`: `0.25m` / `0.5m`）で辺接着パッキングします。
  - 外窓・扉（`doors.json` 統一扉高・施錠率）・アーチ開口・遮蔽物（家具）・容疑者/民間人配置も可動域クリアランスを守ってシードから一括生成され、万一通常試行が上限に達した場合も選択済み階層構成を維持する決定論的最小構成器がフォールバックとして成立を保証します。
- **多階層バリエーション（`B1` / `1F` / `2F`）と階層別独立フットプリント**:
  - テンプレートの `storyProfiles` 重みに応じて、**平屋（`[0]`：1Fのみ）・2階建て（`[0, 1]`：1F+2F）・地下付き平屋（`[-1, 0]`：B1+1F）・3階層（`[-1, 0, 1]`：B1+1F+2F）**が選択されます（`house_compact` は平屋 / 2F / B1+1F の最大2層構成、`house`・`embassy` は全4構成、`embassy` は最大2階段コア対応）。
  - ガレージ等の平屋屋根制約（`flat_roof_only`）、2層吹き抜け（`double_height`）、2Fセットバックおよびルーフテラスにより各階が単なるコピーにならない立体構造を形成し、階段の人体掃引頭上クリアランス・床スラブ開口・落下防止壁・地下スラブ音響遮蔽・Squad の多階層階段経路探索と連携します。
- **敷地直交8変換（回転・鏡映）**:
  - 原点 `(0, 0)` 中心対称（`2 * snap` 整数倍）の敷地上で、建物全体の直交回転（`0° / 90° / 180° / 270°`）× 左右鏡映（反転有無）の**全8通りの直交変換**を格子整数座標系で無誤差適用します。突入アプローチの方角・初期スポーン・味方隊員展開位置・扉ヒンジ/開放方向・外窓法線・階段進行方向がすべて連動して変化します。
- **シードの扱いと JSON 調整**:
  - ステージ選択や「別の間取りを生成」で新しいシード、リトライ（`R`）では同じシードを使用します。ブリーフィング画面にシードが表示され、シード入力欄・URL（`?stage=random_house&seed=12345`）・コンソールから同じ間取りを完全再現できます。
  - 階層プロファイル重み・目標面積・建築モジュール（寸法・個数・家具・サブ室）・動線ループ数・敷地変換規則・施錠率・人数などはテンプレート JSON のみで調整できます。
